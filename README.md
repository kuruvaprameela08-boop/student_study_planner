# 📚 Student Study Planner

A smart Java-based application to help students organize tasks, track study progress, and manage time effectively.

*Tech Stack:* Java | MySQL | HTML | CSS | JavaScript | JDBC

### ✨ Features
- Add, Edit, Delete study tasks
- Set deadlines and priorities
- Track progress with dashboard
- User-friendly web interface
- MySQL database integration

### 📁 Project Structure
- src/ - Java source code
- frontend/ - HTML, CSS, JS files
- database/ - SQL scripts
- lib/ - Required libraries

### 🚀 How to Run
1. Create database: Run database/study_planner.sql in MySQL
2. Update DB credentials in src/StudyPlanner.java
3. Compile: javac -cp ".;lib/*" src/*.java
4. Run: java -cp ".;lib/*;src" StudyPlanner
5. Open frontend/index.html in browser
